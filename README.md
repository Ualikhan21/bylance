# Bylance — Интернет-магазин электроники и Trade-In в Алматы

Официальный веб-каталог магазина оригинальной техники **Bylance** с интерактивным калькулятором онлайн-оценки и выкупа iPhone, корзиной покупок и мгновенным оформлением заказов через WhatsApp.

---

## 🌟 Ключевые возможности

### 1. Каталог оригинальной техники
- **Apple**: Линейки iPhone (включая актуальные поколения iPhone 16 / 17 / 18 Pro), MacBook Air и Neo, iPad Air (M4), Apple Watch Series 11 и SE, AirPods.
- **Dyson**: Оригинальные стайлеры Airwrap с заводской гарантией.
- **Фототехника и гаджеты**: Камеры Sony и Canon, дроны DJI, смарт-очки Ray-Ban Meta, Яндекс Станции.
- **Интерактивные карточки**: Переключение цвета, объёма памяти, типа SIM (SIM / eSIM), размера корпуса и расчёт актуальной цены под выбранный способ оплаты.
- **Индивидуальные цены по цветам**: Поддержка эксклюзивных цен для отдельных цветов (например, отдельный официальный прайс-лист для цвета Burgundy на iPhone 18 Pro и Pro Max).
- **Поиск и фильтры**: Мгновенная фильтрация по подкатегориям и быстрый текстовый поиск по моделям.

### 2. Гибкие способы оплаты
- **Акционная цена**: Специальное выгодное предложение.
- **Наличные**: Максимальная скидка при оплате наличными.
- **Рассрочка Kaspi (0-0-12 / 0-0-24)**: Расчёт ежемесячного платежа без переплат.
- **Рассрочка Halyk Bank**: Оформление через приложение Halyk.

### 3. Интерактивный калькулятор оценки и Trade-In iPhone
- Поддержка моделей от iPhone X, XR, 11 до iPhone 18 Pro Max.
- Учёт ёмкости накопителя (от 64 ГБ до 1 ТБ).
- Динамический ползунок состояния батареи (АКБ) с шагом до 1%.
- Градация состояния корпуса: «Идеальное», «Хорошее», «Среднее», «Следы падений».
- Дополнительные параметры: замена дисплея, замена АКБ, отсутствие коробки, блокировка iCloud.
- Мгновенный перенос суммы выкупа как скидки Trade-In прямо в корзину покупок.

### 4. Оформление заказа и корзина
- Заказ в 1 клик с любой карточки товара сразу в WhatsApp с готовой спецификацией.
- Многопозиционная корзина с индивидуальным выбором способа оплаты для каждого товара.
- Автоматический вычет скидки Trade-In из итоговой суммы заказа.
- Отправка сформированного списка покупок менеджеру в WhatsApp.

### 5. Современный UI / UX
- Автоматическая адаптация под системную тему устройства (светлая / тёмная) с возможностью ручного переключения.
- Оптимизированный мобильный интерфейс с фиксированной нижней навигацией и блокировкой фонового скролла при открытых шторках.
- Плавные скелетоны загрузки изображений и WebP-оптимизация.

## 🚀 Установка и запуск

1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/Ualikhan21/bylance_-beta-.git
   cd bylance_-beta-
   ```

2. **Установка зависимостей:**
   ```bash
   npm install
   ```

3. **Запуск сервера разработки:**
   ```bash
   npm run dev
   ```
   Приложение будет доступно по адресу `http://localhost:3000`.

4. **Сборка для продакшна:**
   ```bash
   npm run build
   ```

5. **Проверка типов TypeScript:**
   ```bash
   npm run lint
   ```

## 🌐 Публикация на GitHub Pages

В проекте уже настроен автоматический деплой через **GitHub Actions** (`.github/workflows/deploy.yml`):

1. Проверьте параметр `base` в файле `vite.config.ts` — он должен совпадать с названием вашего репозитория на GitHub:
   - Если репозиторий называется `bylance` → `base: '/bylance/'`
   - Если репозиторий называется `bylance_-beta-` → `base: '/bylance_-beta-/'`
   - Если привязан свой домен (например, `bylance.kz`) → `base: '/'`
2. Загрузите код в ветку `main` вашего репозитория на GitHub.
3. Откройте репозиторий на GitHub → **Settings** → **Pages**.
4. В разделе **Build and deployment** → **Source** выберите **GitHub Actions**.
5. После завершения workflow в разделе **Actions** сайт будет автоматически опубликован по адресу `https://<ваш-логин>.github.io/<название-репозитория>/`.
